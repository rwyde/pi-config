# Software Workflow

Use the requested phase only. Read its reference relative to this skill:

- Plan: `references/plan.md`
- Implement: `references/implement.md`
- Review: `references/review.md`
- Commit: `references/commit.md`

Plan, Implement, and Review must also apply the `simple-software` skill.

Treat the user's stated requirements as the scope. Do not turn general quality concerns into new acceptance criteria. Prefer the shortest path that produces something concrete the user can inspect, then stop for feedback.
